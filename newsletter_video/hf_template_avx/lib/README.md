# Vendored libraries

GSAP 3.14.2 (`gsap.min.js`) and the plugins this template uses (`SplitText`, `DrawSVGPlugin`,
`CustomEase`), copied from the `gsap@3.14.2` npm package's `dist/`. Since GSAP 3.13 the whole
toolset, plugins included, is free for commercial use under GreenSock's standard "no charge"
licence (https://gsap.com/standard-license, https://gsap.com/blog/3-13/).

Vendored so a render never fetches anything from the network.
